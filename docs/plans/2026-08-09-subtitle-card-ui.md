2026-08-09。來源：使用者截圖點名卡片上的 ⏱ 圖示「位置怪怪的、不明白為什麼標在那裡」
（誤讀為氣口標示），加上綠色講者數字與鏡頭 A/B 膠囊語意撞車。

## 設計原則：識別 / 屬性 / 操作 三區分離

- **識別區（左欄 66px，恆顯）**：⠿ 把手、#idx、起訖時間（點擊 seek 行為不變）、
  講者膠囊、⚠ 待複查旗標；子卡的時長／語速／警示不動。
- **屬性語言統一**：講者＝實心色膠囊、文字改「講N」（例「講3」，tooltip 保留）；
  鏡頭 A/B＝描邊膠囊（transparent 底＋色框），tooltip 補「鏡頭」字樣，位置與點擊切換行為不動。
- **操作區（末欄直排，hover 浮現）**：由上而下 ×（刪除）、「調時間」鈕（⏱ 圖示＋按鈕外觀：
  邊框、hover 底色）、「看過」鈕（僅待複查卡）。預設 opacity 0.25，卡片 hover／focus-within／
  `.editing-time` 時 opacity 1；用 opacity 過渡，不用 display 切換（零版面位移）。

## 改法

1. `app.js` `renderCards()`：⏱ 從 `card-time` 欄移到末欄操作區，與 `card-del`、
   `card-review-seen` 同欄直排；`card-speaker-tag` 文字改 `講${n}`；末欄 24px 改 auto。
2. `app.js:1289-1298` 插入新卡路徑的 ⏱ 同步搬移（兩個渲染路徑都要改到，缺一即假完成）。
3. `app.css`／`tokens.css`：操作欄 opacity 規則、「調時間」按鈕外觀、講者實心／鏡頭描邊
   兩套膠囊樣式。鏡頭膠囊維持可點擊的視覺回饋。
4. 行為零變更：seek、toggleTimeEdit、刪除、看過、拖曳、Enter 切卡、行首 Backspace 併卡
   全部不動——本梯只動 DOM 組裝位置與 CSS。

  續顯到焦點移走。計畫明寫的行為，非缺陷，留意即可。
