# 完全離線本機模型整合計畫

日期：2026-09-06
分支：`vs/subtitle-polish-flow`
狀態：已完成並安裝測試版 App

## 目標

讓 JOIN Podcast Toolkit 在未安裝 Claude Code、沒有 API 金鑰、沒有網路時，仍能完成：

1. 字幕語意校對。
2. 上架文案生成。

## 技術決策

- 模型：Qwen3 4B Q4_K_M，模型檔約 2.4GB，Apache 2.0 授權。
- 推論器：`llama.cpp`，MIT 授權，Apple Silicon 原生執行。
- 發布方式：模型與推論器放入 App 的 `Contents/Resources/local-llm`，不放進 Git。
- 開發方式：可由環境變數指定推論器與模型；正式 App 自動使用內建資源。
- 相容方式：保留 Claude Code 作為手動指定的舊路徑，但 `auto` 永遠優先使用內建本機模型。

## 實測選型結果

- Qwen3 0.6B Q8_0：610MB；輸出錯誤 JSON 且混淆欄位，不採用。
- Qwen3 1.7B Q8_0：約 1.7GB；漏修填充詞並改錯台灣慣用字，不採用。
- Qwen3 4B Q4_K_M：約 2.4GB；字幕樣本三題全對，能產生完整合法上架文案 JSON，採用。

## 工作項目

### 一、本機模型執行器

- 新增資源定位、離線推論、逾時、錯誤碼與 JSON 抽取。
- 所有呼叫固定加入離線模式與關閉思考輸出。
- 模型或執行器缺失時回傳可理解的錯誤，不靜默跳過。

### 二、字幕校對整合

- 新增 `local_llm` provider。
- 本機格式改用固定的 `idx`／`text` 陣列，避免動態鍵名造成約束器失敗。
- `auto` 優先順序改為內建本機模型，再到手動安裝的 Claude Code。
- 本機模型採單工分塊，避免同時載入多份 2.4GB 權重。

### 三、上架文案整合

- 預設改由本機模型生成。
- 保留既有章節清洗、成品時間軸與文件渲染安全層。
- 驗證模型輸出必備欄位，缺件時不寫出半成品。

### 四、App 打包

- 建立本機模型 sidecar 清單與雜湊檢查。
- 建立可攜式 `llama.cpp` 執行器與模型 stage。
- 打包時檢查、注入、簽章並保留兩套開源授權文件。
- 更新 README、CLI 與錯誤提示，移除「必須安裝 Claude Code」的說法。
